RPM/RPD mean requests per minute/day; TPM/TPH/TPD mean tokens per minute/hour/day. Limits can change by account, tier, region and shared usage. Browser-readable quota headers and Retry-After further restrict pacing. The app's rolling daily guards can be stricter than provider reset clocks. Timing is an estimate, never a promise of throughput. Claude's independent token buckets and Cerebras's cache/hour buckets are represented conservatively, not claimed as fully replicated provider accounting.

## Request compatibility and verification

OpenAI GPT-6 presets retain the documented Chat Completions JSON schema path: Luna uses `reasoning_effort: none`, Sol/Astra use `low`. Claude presets now send native `output_config.format` JSON schemas and parse text while ignoring thinking blocks, avoiding forced-tool incompatibility on Claude 5.5. [OpenAI schema guide](https://developers.openai.com/api/docs/guides/structured-outputs), [Claude structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs).

Gemini uses its generation JSON schema; Groq and dedicated Cerebras use supported strict schemas. Custom compatible endpoints retain JSON object mode because their schema implementation is unknown. The compatible default is now GPT-OSS 20B; Groq's Llama 3.3 preset is enterprise-only. [Groq structured outputs](https://console.groq.com/docs/structured-outputs), [Cerebras structured outputs](https://inference-docs.cerebras.ai/capabilities/structured-outputs).

The supplied Gemini key was used for the PDF analysis described in [live evaluation](LIVE-GEMINI-ANALYSIS.md). Other providers were checked against official documentation and tested with mocked API responses; no other live account credentials were supplied. The official Cerebras pricing table did not expose verifiable token rates in the fetched page, so the app deliberately leaves those charges unknown. Pushing the accompanying application changes to main triggers the repository’s configured deployment pipeline; a successful local build does not confirm a finished deployment.
